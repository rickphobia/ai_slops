# Swarm prototype

`swarm-prototype.html` is a throwaway, single-file prototype used on 2026-10-02 to find the game's feel, now with the grotesque art. The spec (`../spec.md`) follows it. It's also the shareable demo.

Use it as a reference for feel and numbers. Don't import from it or extend it: it has no tests, no types and no structure. Open it in a browser to play.
